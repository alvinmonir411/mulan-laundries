# Mulan Laundries NYC 🧺

The official high-performance web platform and real-time operations portal for **Mulan Laundries**, New York City's premier commercial and residential laundry service provider.

- **Production URL**: [https://www.mulanlaundries.com](https://www.mulanlaundries.com)
- **Deployment Platform**: Vercel Fluid Compute
- **Repository**: [https://github.com/monir411/laundy](https://github.com/monir411/laundy)

---

## 🚀 Key Features

- **Next.js 16 (App Router) & React 19**: Ultra-fast SSR/ISR edge rendering with optimized Core Web Vitals (sub-50ms INP, instant LCP).
- **Central Lead Management Portal**: Admin-only CMS with real-time Neon PostgreSQL persistence, status lifecycle progression, and lead filtering.
- **Dynamic Cloudinary Media Management**: Cloudinary CDN asset delivery with instant cloud upload, auto-compression (`f_auto,q_auto`), and live slot swapping.
- **Automated Dispatch & Notifications**: Resend integration sending direct email alerts on customer submissions.
- **SEO & Performance Tuned**: Perfect semantic markup, JSON-LD Schema markup, dynamic OpenGraph metadata, and full 5-borough coverage in New York City.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16.4 / React 19
- **Styling**: Tailwind CSS & Lucide Icons
- **Database**: Neon Serverless PostgreSQL (`@neondatabase/serverless`)
- **Media CDN**: Cloudinary Media Library
- **Email Service**: Resend API
- **Deployment & Hosting**: Vercel
